## 精選專案

### [StockPilot｜庫存與營運工作台](https://github.com/EdChen0321/StockPilot)

為小型商家規劃的開源專案，串起商品、庫存、訂單、進出貨、採購與銷售分析。AI 助理透過固定的唯讀工具查詢營運資料，不自動修改訂單或庫存。

我把過去處理營運流程的經驗轉成產品規劃與實作練習：先定義日常工作與資料口徑，再安排功能範圍、設計操作流程，並逐步以測試與實際操作核對結果。專案仍在開發與驗收中；[README](https://github.com/EdChen0321/StockPilot#readme) 說明目前能做什麼，[Roadmap](https://github.com/EdChen0321/StockPilot/blob/main/ROADMAP.md) 記錄下一步及尚待驗證的部分。

## 我的工作方式

1. **先理解現場**：訪談使用者，觀察原有報表、單據與操作習慣。
2. **把問題變成可開發的範圍**：整理正常流程、例外情境與驗收條件；依必要性、使用頻率與替代方案排序。
3. **用原型與資料核對**：透過 Figma 或 Lovable 試用流程，使用 Excel、Google Analytics 與系統資料檢查假設。
4. **上線後看結果**：追蹤作業時間、錯誤與使用情況，繼續調整。
