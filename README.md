## 實務成果

- **把現場流程做成系統：** 規劃支援逾 1,000 個 SKU 的庫存與出貨系統，出貨前置作業由 30–60 分鐘縮短至 5–10 分鐘，每月節省約新台幣 10 萬元外部 ERP 租用費。另以原型試用規劃物料管理系統，取代 Excel 後，團隊溝通時間減少 30%。
- **讓資料更快支持決策：** 定義銷售資料清理與查詢規則，運用 OpenAI Codex 輔助製作工具，將單次報表作業由約 1–2 小時縮短至 15 分鐘內；規劃 KOL 訂單分類與彙整規則，將合作報表作業由 2 小時縮短至 20 分鐘。
- **追蹤上線後的營運成效：** 設計包裹到店提醒的規則與內容，並按月追蹤未取貨率；上線前約 3.4%–3.5%，上線後約 0.8%–0.9%。

## 工作方式

**前期調查｜找出問題並決定先做什麼**

走進實際作業流程，訪談使用者，對照訂單、庫存或銷售資料，確認問題發生在哪一步。把正常流程、例外情境與替代做法整理清楚，再依必要性、使用頻率和可用工程資源排開發順序。

**中間開發｜讓需求落到可操作的流程**

先用原型和操作人員確認規則與畫面，再把需求、誤操作及退回等情境交給工程師實作。開發過程中持續釐清細節，完工後用實際工作情境試用與驗收。

**後面追蹤｜用結果判斷是否真的改善**

上線後追蹤作業時間、錯誤與使用回饋；營運調整則看流量、銷售、成本等數字。根據結果修正流程，並決定下一步要優先改善的問題。
