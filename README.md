# 陳昱穎 · Ed Chen

**資深電商營運專員｜內部系統產品經理 × 電商營運**

我有約五年半的內部系統規劃與電商營運經驗。主導需求訪談、開發優先順序與驗收，並與工程師合作上線支援逾 1,000 個 SKU 的庫存與出貨系統。2021 年 2 月至 2024 年 2 月以內部系統規劃為主，之後轉任電商營運，持續支援系統需求。

目前尋找產品管理相關機會。

## 核心技能

- **產品技能：**訪談使用者、整理作業流程與需求、排定開發順序；透過原型試用與驗收，確認功能符合實際操作。
- **數據分析與營運管理：**分析流量與銷售資料，調整商品曝光和 KOL 合作；檢查運費與出貨成本，減少不必要的支出。

## 實務成果

**庫存與出貨系統｜縮短作業時間、降低成本**

我負責庫存與出貨系統的需求規劃與驗收，與工程師合作上線後，以這套系統取代外部 ERP。

- 出貨前置作業：30–60 分鐘 → **5–10 分鐘**
- 取代外部 ERP：每月節省約 **新台幣 10 萬元**租用費

**物料管理｜以系統取代 Excel 物料表**

我用互動原型讓操作人員試用，依回饋訂出商品用量、共用物料、誤操作與退回的處理規則，供工程師開發與測試。系統上線後取代 Excel 物料表，團隊溝通時間減少 **30%**。

**電商營運｜商品管理與營收成長**

我負責商品管理與電商營收，根據流量與銷售數據，和行銷團隊一起調整營運做法。任職期間，月營收較接手時成長約 **60%**。

**銷售查詢工具｜減少人工整理報表**

定義資料清理與查詢規則，以 OpenAI Codex 輔助製作工具，核對既有系統的結果後投入使用。

- 單次報表作業：1–2 小時 → **15 分鐘內**

**包裹取貨提醒｜改善未取貨問題**

設計到店第 4 天仍未取貨的自動提醒，負責通知規則、內容與測試，並按月追蹤成效。

- 未取貨率：3.4%–3.5% → **0.8%–0.9%**

**KOL 合作分析｜縮短報表整理時間**

規劃訂單分類與彙整規則，持續統計合作內容帶來的訂單，並以營收、ROAS 與商品組成協助評估推廣頁面及後續合作。報表改以 KOL 為單位取得，減少逐活動查詢的漏選。

- Excel 報表整理：2 小時 → **20 分鐘**

**運費與商品曝光｜依資料調整營運**

- 分析團隊訂單運費，發現免運政策使公司每月負擔約新台幣 **4–5 萬元**；經試算與討論後調整收費與免運門檻，調整後不再由公司補貼。
- 依 Google Analytics 流量與銷售資料找出有穩定搜尋及購買需求、但未在首頁曝光的商品；增加首頁曝光後，該商品銷量提高約 **10%**。

## 工作方式

**01　前期調查：釐清問題與優先順序**

- 訪談使用者、觀察作業，搭配資料找出卡住的環節。
- 比較需求必要性、使用頻率與替代方案，安排開發順序。

**02　開發推進：確認設計與驗收成果**

- 讓使用者試用原型，確認流程、規則與例外情境。
- 與工程師釐清需求，依實際操作情境測試與驗收。

**03　上線追蹤：確認成效並持續改善**

- 比較上線前後的作業時間與營運數字，確認改善效果。
- 收集使用回饋，修正流程並安排下一步改善。
