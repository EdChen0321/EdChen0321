## 實務成果

**庫存與出貨系統｜縮短作業時間、降低成本**

主導需求訪談、流程設計與驗收，與工程師建置支援逾 1,000 個 SKU 的系統。

- 出貨前置作業：30–60 分鐘 → **5–10 分鐘**
- 取代外部 ERP：每月節省約 **新台幣 10 萬元**租用費

**銷售查詢工具｜減少人工整理報表**

定義資料清理與查詢規則，以 OpenAI Codex 輔助製作工具，核對既有系統的結果後投入使用。

- 單次報表作業：1–2 小時 → **15 分鐘內**

**包裹取貨提醒｜改善未取貨問題**

設計到店第 4 天仍未取貨的自動提醒，負責通知規則、內容與測試，並按月追蹤成效。

- 未取貨率：3.4%–3.5% → **0.8%–0.9%**

## 工作方式

**01　前期調查：釐清問題與優先順序**

- 訪談使用者、觀察作業，搭配資料找出卡住的環節。
- 比較需求必要性、使用頻率與替代方案，安排開發順序。

**02　開發推進：確認設計與驗收成果**

- 讓使用者試用原型，確認流程、規則與例外情境。
- 與工程師釐清需求，依實際操作情境測試與驗收。

**03　上線追蹤：確認成效並持續改善**

- 比較上線前後的作業時間與營運數字，確認改善效果。
- 收集使用回饋，修正流程並安排下一步改善。
