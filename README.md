## 關於我

我有約五年半的內部系統規劃與電商營運經驗。曾訪談使用者、整理流程與例外情境、安排需求優先順序，並與工程師合作完成功能驗收。我也會用訂單、銷售與成本資料核對改動是否解決問題。

## 代表成果

- **庫存與出貨系統：** 支援逾 1,000 個 SKU；訂單匯入後 5 分鐘內產出備貨與補貨清單。我負責從零到一規劃需求、流程與驗收，與工程師協作完成高頻出貨功能。
- **銷售資料查詢：** 將單次報表作業由約 1–2 小時縮短至 15 分鐘內。我定義資料清理與查詢規則，以 OpenAI Codex 輔助製作工具，並與既有系統核對結果。
- **KOL 合作分析：** 將重複整理報表的時間由 2 小時縮短至 20 分鐘。我規劃訂單分類與彙整規則，讓營收、ROAS 與商品組成可用於合作評估。
- **包裹取貨提醒：** 按月追蹤的未取貨率由約 3.4%–3.5% 降至 0.8%–0.9%。我設計通知時點、內容與測試方式，上線後持續追蹤結果。

## 我的工作方式

1. **先理解現場：** 訪談使用者，觀察原有報表、單據與操作習慣。
2. **把問題變成可執行的範圍：** 整理正常流程、例外情境與驗收條件，安排需求優先順序。
3. **用原型與資料核對：** 試跑操作流程，檢查數字與來源；上線後持續追蹤作業時間、錯誤與使用情況。
