# 陳昱穎 · Ed Chen

**產品經理｜電商營運與內部系統規劃**

我有約五年半的電商營運與產品規劃經驗。從 App 營運與客服開始，後來負責電商商品管理，並與倉管、營運人員及工程師合作，把訂單、庫存和出貨流程中的問題轉成可開發、可驗收的功能。

曾任菜鳥娛樂有限公司電商營運／產品經理（2021.02–2026.07）。目前尋找產品經理機會。

## 工作成果

| 系統或功能 | 我的工作 | 上線成果 |
| --- | --- | --- |
| 庫存與出貨系統 | 從零到一主導需求訪談、流程設計、功能排序與驗收，與工程師合作上線。 | 支援逾 1,000 個 SKU。每日出貨前置作業由 30–60 分鐘縮短至 5–10 分鐘，取代外部 ERP 後每月節省約新台幣 10 萬元租用費。 |
| 官網素材管理系統 | 規劃 Banner 排程需求，在平台缺少可用 API 的情況下，與工程師評估圖片覆蓋方案及顯示限制。 | 營運人員可在上班時間完成設定與檢查，減少午夜手動換圖及操作出錯的風險。 |
| 合作單位銷售資料分析系統 | 定義合作創作者的訂單歸屬及資料彙整規則。 | 報表處理時間由約 2 小時縮短至 20 分鐘，團隊可依營收、ROAS 與商品組成檢視合作成效。 |
| 包裹取貨提醒 | 定義到店第 4 天仍未取貨時的通知規則與內容，負責測試並按月追蹤。 | 以送達超商的包裹為基準，未取貨率由 3.4%–3.5% 降至 0.8%–0.9%。 |
| 物料管理系統 | 透過訪談及互動原型確認作業流程，定義商品用量、共用物料與異常處理規則。 | 系統取代 Excel 物料表，團隊每週減少 3 小時溝通時間。 |
| 銷售資料查詢工具 | 定義資料清理與查詢規則，以 OpenAI Codex 輔助製作工具，並與既有系統核對不同期間的查詢結果。 | 單次報表作業由約 1–2 小時縮短至 15 分鐘內。 |

## 工作方式

- **需求與優先順序**：訪談使用者並梳理流程，依需求必要性、使用頻率及現有替代方案安排開發順序。
- **原型與驗收**：用互動原型與操作人員確認業務規則，撰寫 PRD，和工程師對齊例外處理與驗收條件。
- **上線與成效追蹤**：比對作業時間、銷售資料或未取貨率，確認功能上線後的改善情況。
